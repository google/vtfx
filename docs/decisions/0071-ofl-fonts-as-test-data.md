# Fonts under the SIL Open Font License as test data

- Status: Approved (2026-10-23, decided by a human in a review of the review queue)
- Date: 2026-10-23
- Related: [0040](0040-sanitized-user-fonts.md) (item 10), [0018](0018-distribution.md), [0060](0060-artifacts-ship-only-checked-classes.md), section 10 of [fonts.md](../design/fonts.md)

## Background

The gating tests of `vtfx-font` use only fonts generated by test code, because committing third-party font files needed a human to check their licenses ([0040](0040-sanitized-user-fonts.md), item 10). Real fonts were checked only outside `check.sh`, on the emulator with the system's own fonts. The candidates were Noto Sans Mono CJK JP, the Noto Sans CJK collection, Sarasa Gothic, BIZ UDGothic, and HackGen, under the SIL Open Font License 1.1, and DejaVu Sans Mono, which the review queue listed with them but which is under the Bitstream Vera license instead, so this decision does not cover it.

## Decision

1. **Fonts under the SIL Open Font License may be committed as test data** (decided by a human).
2. **They are never part of the distributed libraries** (decided by a human): no published artifact (jar, AAR, or their sources and documentation jars) contains them, and no main source set refers to them. Only test source sets read them.
3. As [0018](0018-distribution.md) requires of all third-party material, they are kept under `third_party/`, one directory per font with its license (`LICENSE`, the font's own license text) and its source and version (`METADATA`), and have no Apache License header.

Which of the candidates to commit, and which tests read them, is chosen when they are added, with their size in mind: the Noto Sans CJK collection is over 100 MB.

## Alternatives considered

- **Keep only generated fonts in the gating tests**: the generated fonts cover the structures that the sanitizer reads, but not the combinations and sizes of real fonts, which today only the emulator checks.
- **Download the fonts during the build**: the tests would depend on the network and on hosts that may change the files; dependency verification ([0035](0035-dependency-verification.md)) covers Gradle dependencies, not ad hoc downloads.

## Impact of reversing

Remove the fonts from `third_party/` and the tests that read them; the gating tests go back to generated fonts only.
