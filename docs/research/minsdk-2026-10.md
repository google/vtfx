# What lowering minSdk below 34 needs (2026-10-19)

A record of the study made on 2026-10-19 before minSdk was lowered from 34 to 29 ([decisions/0039](../decisions/0039-minsdk-29.md)). It records what was found at that date and is not kept up to date.

## What the build needs below 34

Lint was run with the minSdk of the Android conventions lowered, on a copy of the tree. The JVM modules (`vtfx-core`, `vtfx-input`, `vtfx-gate`, `vtfx-session`) were included by compiling their main sources in a scratch Android library, because lint does not check Android API levels in JVM modules. The dependencies (Compose UI and Foundation 1.12.1, activity-compose 1.13.0, androidx.core 1.18.0) all have minSdk 23.

| API | Use | Where |
|---|---|---|
| 26 | `java.util.Base64` | OSC 52 in `Emulator` (`vtfx-core`) and `TerminalGate` (`vtfx-gate`) |
| 26 | `EditorInfo.IME_FLAG_NO_PERSONALIZED_LEARNING` | `TerminalInputConnection.configure` |
| 29 | `RenderNode`, `Canvas.drawRenderNode` | `LineCache` and `TerminalRenderer.draw` |
| 29 | `Paint.underlineThickness`, `Paint.underlinePosition` | `TerminalRenderer` |
| 30 | `EditorInfo.setInitialSurroundingText` | `TerminalInputConnection.configure` |
| 31 | `SurroundingText` | `TerminalInputConnection.getSurroundingText` |

With minSdk 29, lint reported only the two uses at API 30 and 31, all in `vtfx-compose`; the JVM modules and `vtfx-gate-android` reported nothing, and the sample app built (`assembleDebug`).

Overrides of methods added later (`replaceText` (34), the `TextAttribute` overloads (33), `requestCursorUpdates(int, int)` (33), `getSurroundingText` (31), `setImeConsumesInput` (31)) are not lint errors; older platforms do not call them.

Robolectric 4.17 supports SDK 29 (it lists SDK 23 and later), but refuses to run an SDK below the minSdk of the manifest ("Requires newer sdk version #34"), so tests at SDK 29 could run only once minSdk was lowered.

## What the platform stops guaranteeing below 34

- **IME edits**: Before API 34, IMEs do not call `replaceText`. They correct text with `setComposingRegion`, `setSelection`, or `deleteSurroundingText` followed by `commitText`. Every trace in `tools/ime-probe/traces/` was recorded on API 36 or 37.
- **Accessibility**: the sensitive mark on the rows has no effect below 34. In the class files, `AndroidComposeViewAccessibilityDelegateCompat` (Compose UI 1.12.1) hides sensitive nodes from requests that `AccessibilityManagerCompat.isRequestFromAccessibilityTool` says are not from a tool, and that method (androidx.core 1.18.0) returns `true` below API 34. `AccessibilityNodeInfoCompat.setAccessibilityDataSensitive` only stores the flag in the extras below 34.
- **Clipboard**: the OS shows a preview of the clipboard on each copy from API 33, and notifies the user of clipboard reads from API 31. From API 29, it lets only the focused foreground app read the clipboard.
