# Module vtfx-gate-android

Carries out with Android APIs the requests that vtfx-gate allowed.

Give an [AndroidClipboard][com.google.vtfx.gate.android.AndroidClipboard] and an
[AndroidUrlOpener][com.google.vtfx.gate.android.AndroidUrlOpener] to the `TerminalSession`.

# Package com.google.vtfx.gate.android
